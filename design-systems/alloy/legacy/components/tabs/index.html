Components

Tabs

A contained, joined tab bar for switching between related content panels. Tabs share borders and collapse them via negative margins to form a seamless row. Supports 2–5 tabs at a fixed 48px height.

Tabs View in Figma ↗ Storybook ↗

Tab Counts

Tab groups support 2 to 5 tabs. Beyond 5, consider a different navigation pattern such as a dropdown menu or pagination.

Code

Minimal HTML for a 3-tab group with content panels. Add data-tabgroup to the tab bar and wire panels with matching data-panel / data-tabgroup-panel attributes.

<!-- Tab bar -->
<div class="tabs tabs--lg" role="tablist" data-tabgroup="my-tabs">
  <button class="tabs__item is-selected" role="tab" aria-selected="true"  data-panel="panel-a">Overview</button>
  <button class="tabs__item"             role="tab" aria-selected="false" data-panel="panel-b">Specs</button>
  <button class="tabs__item"             role="tab" aria-selected="false" data-panel="panel-c">Gallery</button>
</div>

<!-- Panels -->
<div class="tabs-panel is-active" id="panel-a" data-tabgroup-panel="my-tabs">Overview content</div>
<div class="tabs-panel"          id="panel-b" data-tabgroup-panel="my-tabs">Specs content</div>
<div class="tabs-panel"          id="panel-c" data-tabgroup-panel="my-tabs">Gallery content</div>

Dos & Don'ts

Do
  • Keep labels short (1–3 words) — tabs are not for long sentences.
  • Always have exactly one tab selected at all times.
  • Use tabs for primary page navigation with 2–5 related panels.
  • Provide a content panel for every tab.
Don't
  • Don't use more than 5 tabs — use a different navigation pattern instead.
  • Don't use tabs when the content on each panel is very similar — use filters instead.
  • Don't rely only on color to communicate the selected state.
