# Brief — t1-vehicle-search

**Source:** Pasted by designer (jrajan) in chat on 2026-07-30.

---

When a user asks something like "find me a Toyota Camry from my inventory," T1 should respond
with something like "I have found 4 Camrys" and show 4 vehicle cards.

Each vehicle card shows:
- YMMM (Year / Make / Model / … )
- VIN
- Stock #
- Image
- Type (Used / New)
- Transmission Type
